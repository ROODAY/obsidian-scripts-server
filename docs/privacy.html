Privacy Policy

Obsidian Scripts Server is a private, single-user application. This policy explains what it accesses and how that data is handled.

Who runs this application

The application is developed and operated by one person, for their own use. It is not offered to the public and does not have other users.

Data the application accesses

  • Google Health sleep data. With the read-only googlehealth.sleep.readonly scope, the application reads the operator's own sleep sessions so it can display a sleep summary in their personal notes.
  • Public Reddit headlines. The application reads publicly available post titles from subreddits chosen by the operator.

The application does not access data belonging to anyone other than its operator.

How data is stored

  • An OAuth refresh token is stored in a secret file on the operator's private server so the application can request fresh access tokens.
  • Health data is fetched on demand to answer a request and is not stored in a database or written to disk by this application.
  • Reddit API credentials are stored in the server's environment configuration.

Sharing and tracking

  • No personal data is sold, rented, or shared with third parties.
  • No advertising, analytics, or tracking scripts are used.
  • The application does not set cookies for visitors to this page.
  • Requests to third-party APIs (Google Health and Reddit) are made directly from the operator's server, subject to those providers' own privacy policies.

Retention and revocation

The OAuth refresh token is kept until it is revoked. Access can be revoked at any time from the Google Account permissions page (myaccount.google.com/permissions). Once access is revoked, the application can no longer read health data.
