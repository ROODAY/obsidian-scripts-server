Personal application

Obsidian Scripts Server

A small, self-hosted web service that retrieves my own health and news data so it can be included in my personal Obsidian notes.

What it does

The server wraps a few scripts that do not run well inside Obsidian and exposes them over HTTP for my personal note templates. It runs on a private server that I administer and is not offered as a public service.

Sleep summary
Reads my own sleep data from Google Health (Fitbit) using the read-only googlehealth.sleep.readonly scope, so a daily note can show last night's sleep.
Reddit headlines
Fetches top headlines from subreddits I choose, for a personal news section in my notes.
Access
Protected by HTTP Basic authentication and available only to me.

Who it is for

This application has exactly one user: its developer. It is not a product, has no other accounts, and does not collect information about anyone else.
